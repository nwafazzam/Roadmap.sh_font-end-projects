# Personal Portfolio Website | Frontend Developer

A professional, fully semantic personal portfolio website built with **HTML5** and **CSS3**, following the strict guidelines and requirements of the [roadmap.sh Portfolio Project](https://roadmap.sh/projects/portfolio-website).

## 📌 Project Overview

This project is designed to showcase my journey, technical skills, academic background, projects, and technical articles as a growing **Frontend Developer**. The primary goal is to master clean semantic layout structures, advanced CSS grid/flexbox techniques, and responsive design without relying on external CSS frameworks.

---

## 🛠️ Built With & Technologies Used

* **HTML5:** Semantic elements (`<header>`, `<nav>`, `<main>`, `<section>`, `<article>`, `<footer>`) to ensure structural clarity and accessibility.
* **CSS3:** Advanced styling utilizing CSS Grid, Flexbox, and custom Media Queries for full responsiveness.
* **SEO & Open Graph:** Fully optimized meta tags and social sharing previews.
* **Version Control:** Git & GitHub.

---

## 📁 Project Structure

```text
├── index.html        # Home page (Overview, Work Experience, Education, Teacher Reviews)
├── projects.html     # Projects showcase page (Grid layout with live and GitHub links)

├── contact.html      # Contact page (Structured interactive contact form)
├── style.css         # Main stylesheet with grid systems and media queries
└── IMG/              # Assets and images folder
✨ Key Features
Semantic Structure: Built from scratch using modern HTML5 tags for optimal SEO and screen reader accessibility.

Responsive Design: Fully adaptive layout across large desktop screens down to mobile devices using CSS Grid and Media Queries.

Interactive UI Elements:

Custom layout design for contact forms and project cards.

"Coming Soon" states for projects currently under development.

Responsive images in articles that automatically adapt or hide on mobile screens.

SEO Optimized: Complete with standard meta tags, keywords, description, and Open Graph protocols for social media sharing.
