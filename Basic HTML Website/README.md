# Basic HTML Website

A multi-page personal website built purely with semantic HTML5, created as part of the **roadmap.sh** Frontend Development challenges.

## 📌 Project Overview

This project demonstrates the fundamentals of building a structured, multi-page website using only standard HTML without CSS or JavaScript. It emphasizes correct semantic layout, accessibility, SEO optimization, and proper navigation between multiple HTML pages.

## 🚀 Features & Structure

* **Semantic HTML5 Elements**: Built using tags like `<header>`, `<nav>`, `<main>`, `<article>`, `<section>`, `<aside>`, and `<footer>`.
* **Multi-Page Navigation**: Smooth linking across different sub-pages via standard relative paths.
* **SEO & Social Meta Tags**: Includes proper page descriptions, keywords, viewport settings, and Open Graph meta tags for preview cards on social platforms.
* **Forms & Media**: Uses forms with input validations, tables for structured data display, and semantic image embeds.
