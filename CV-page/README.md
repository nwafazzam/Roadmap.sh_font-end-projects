# Single-Page CV

In this project, we create a single-page CV (Curriculum Vitae) using only HTML.

## Key Features

- Built strictly using pure, semantic HTML tags to ensure clean code structure and web accessibility.

- Includes essential SEO meta tags to help search engines
index the page properly.

- Implements Open Graph (OG) tags to provide rich link previews when shared on social media.

- Features a custom favicon for proper browser tab branding.
